1.Descendant combinators

Matches all the elements that are descendants(children, grandchildren, etc,.) of a specified element.

Paragraph 1 in the div.

Paragraph 2 in the div.

Paragraph 3 in the div.

This will also change.

2.Child combinators

Selects all the span elements that are direct children of a (specified) div element using (>).

Ex: Span 1 is in the div. Span 2 is also in the div.

This will not change

3. Next Sibling Combinator

Selects the first element that is placed immediately added after div end tag(/div) element using (+).

h1 in the div.

First h1 after div

Second h1 after div

Selects all the h3 elements that are placed immediatley added after div end tag (/div) element using (~).
